
# Azure Air Cargo & SLA Logistics Lakehouse

End-to-end Data Engineering project built on **Microsoft Azure** and **Azure Databricks** using the Medallion Architecture (Bronze, Silver, Gold).

## Business Problem
Monitoring live European air traffic around major cargo hubs, correlating flight congestion with real-time weather conditions, and identifying Customer Care SLA breach risks for priority cargo shipments.

## Target Tech Stack
- **Cloud:** Microsoft Azure (ADLS Gen2, Event Hubs, Azure Functions, Key Vault)
- **Data Platform:** Azure Databricks (PySpark, Databricks SQL, Delta Lake, Unity Catalog, Workflows)
- **CI/CD & Quality:** GitHub Actions, pytest
- **BI:** Power BI / Databricks Dashboards
